# 🍻 Otto's Bachelor Party Website

A modern, interactive bachelor party invitation website with countdown timer, RSVP system, and fun interactive features.

## 🚀 Features

- Sticky navigation with smooth scrolling
- Animated tab system for content organization
- Live countdown timer
- Interactive dare generator
- RSVP form with localStorage
- Google Maps integration
- Share functionality (WhatsApp, Facebook, copy link)
- Fully responsive design
- Smooth animations and transitions
